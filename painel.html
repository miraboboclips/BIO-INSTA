Como criar o token (1 vez só)
  1. Abra github.com/settings/personal-access-tokens/new
  2. Nome: “Painel Mirabobo”. Validade: a que preferir.
  3. Repository access → Only select repositories → escolha BIO-INSTA.
  4. Permissions → Contents → Read and write.
  5. Clique em Generate token, copie e cole no campo acima.
